# 桑山 大輝 (Taiki Kuwayama) - 自己紹介＆お問い合わせポートフォリオ

モダンなデザインと常時動くバックグラウンドアニメーションを取り入れた、レスポンシブWeb対応の自己紹介＆お問い合わせページです。

---

## ✨ 特徴 (Features)

- **動的な背景アニメーション (Dynamic Animated Background)**
  - CSS `@keyframes` を使用したグラデーション背景アニメーションと、浮遊するオーブ（球体）のエフェクト。
- **モダンなUIデザイン (Glassmorphism & Micro-interactions)**
  - `backdrop-filter` を活用したすりガラス風カードデザイン（Glassmorphism）。
  - ホバー時の拡大・浮き上がりエフェクトやスムーズなアニメーション。
- **レスポンシブ対応 (Responsive Design)**
  - Tailwind CSS を活用し、スマートフォン・タブレット・PCなどあらゆる画面サイズに最適化。
- **インタラクティブなフォーム (Interactive Contact Form)**
  - 送信後のフィードバックメッセージ表示機能を搭載。

---

## 🛠️ 使用技術 (Tech Stack)

- **HTML5**
- **CSS3** (CSS Animations, Glassmorphism, Flexbox/Grid)
- **Tailwind CSS** (CDNを使用)
- **JavaScript (ES6+)** (フォーム制御)
- **Google Fonts** (Inter)
